# novelai-auto-generate

NovelAI の画像生成ボタンを自動でくり返し押すブラウザ拡張機能です（Chrome / Edge / Firefox）。

> **非公式ツールです。** NovelAI（Anlatan）とは関係がなく、公式に認められたものではありません。使う前に下の「注意」を読んでください。

## インストール

### Chrome / Edge
1. このリポジトリをパソコンに置く（`git clone` するか、GitHub の「Code → Download ZIP」で落として展開）
2. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開く
3. 「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension` フォルダを選ぶ

### Firefox
1. `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」を押し、`extension/manifest.json` を選ぶ
3. 拡張機能の管理画面で、novelai.net へのアクセスが許可されているか確認する

Firefox の「一時的なアドオン」は Firefox を再起動すると消えるので、そのたびに読み込み直します。

## 更新のしかた
1. 新しいファイルを取ってくる（`git pull`、または ZIP を落として上書き）
2. 拡張機能の画面で、この拡張機能の「更新（↻）」ボタンを押す（Firefox は「再読み込み」）
3. NovelAI のタブを再読み込みする

## 使い方
https://novelai.net/image を開くと右下に操作パネルが出ます。設定は保存され、次回も引き継がれます。

- **間隔**: 生成が終わってから次に押すまでの待ち時間
- **最大回数**: 生成ボタンをこの回数押したら停止（0 = 無制限）。画像の枚数ではありません
- **連続上限**: 「開始」からこの時間がたったら停止（初期値 1 時間、最大 24 時間、0.5 時間刻み）。生成中に時間が来たときは、その生成が終わってから止まります。最大回数とは別に働き、先に来たほうで止まります
- **Anlas 消費時は止める**: ボタンに Anlas の消費量が表示されたら停止
- **エラー表示で止める**: NovelAI が生成エラー（混雑、生成失敗など）を表示したら停止。見分け方は下の「エラーの見つけ方」を参照
- **止まったら通知**: 自動生成が止まったとき、止まった理由をブラウザ通知で知らせます（「手動」で止めたときは出しません）。裏のタブで動かしていても気づけます。通知を押すとそのタブが前に出ます

通知が出ないときは、OS 側でブラウザの通知が許可されているか（Windows なら「設定 → システム → 通知」、Mac なら「システム設定 → 通知」）、集中モード・おやすみモードになっていないかを確認してください。v1.4.0 で通知の権限を追加したので、v1.3.0 以前から更新した場合は拡張機能の「更新（↻）」を忘れずに押してください。

### エラーの見つけ方
本物の NovelAI でエラーを起こして確かめたわけではないので、次の前提で見つけています。うまく止まらない、または関係ない表示で止まるときは知らせてください。

- NovelAI はエラーを画面の端に出る小さな通知（トースト）で知らせる、という前提です。NovelAI はトーストに react-toastify という部品を使っているとみて、その部品の目印（`Toastify__toast`）と、一般的な目印（クラス名に `toast` を含む要素、`role="alert"` の要素）を探します
- 見るのは「開始」を押したあとに新しく出たトーストだけです。開始前から出ていたものでは止まりません
- そのトーストがエラー用の見た目（クラス名に `error` を含む、例: `Toastify__toast--error`）か、文言にエラーらしい言葉（`error` `failed` `too many` `concurrent` `busy` `try again` `エラー` `失敗` `混雑` など）を含むときに、エラーとみなして止めます
- トースト以外の形（生成ボタンの近くに赤い文字が出る、ダイアログが出る、など）でエラーが出る場合は見つけられません。そのときは、エラーが出たまま押し続けてしまいます

パネルの動かし方:

- **移動**: パネルの上の段（タイトルの行）をドラッグすると、好きな場所に動かせます。ダブルクリックすると右下に戻ります
- **たたむ**: 右上の「−」を押すと、タイトルの行だけになります。「＋」で元に戻ります
- タイトル左の丸は、緑なら実行中、灰色なら停止中です（たたんでいても分かります）
- 置いた場所とたたんだ状態は保存され、次回も引き継がれます

## 動作確認の状況
本物の NovelAI の画面で、Chrome 系ブラウザでの動作を確認しました（v1.1.2）。v1.4.0 の「エラー表示で止める」は、本物の NovelAI のエラー表示ではまだ試していません（上の「エラーの見つけ方」を参照）。Firefox ではまだ試していません。NovelAI の画面が変わると、ボタンが見つからない、または生成が終わったことを判定できなくなる場合があります。

## うまく動かないとき
次の 2 つを知らせてもらえると直しやすくなります。

1. **どこで止まったか**: パネルが出ない／「開始」を押しても何も起きない／1 回だけ押して止まる／押し続けて止まらない、など
2. **ステータス欄の表示**: パネルの一番下に出ている文字

ステータス欄の表示の意味:

| 表示 | 意味 |
| --- | --- |
| `待機中` | まだ開始していない |
| `ボタンが見つかりません…` | 生成ボタンを見つけられていない（ボタンの文字が想定と違う可能性） |
| `クリック N 回目` | ボタンを押した直後 |
| `生成中… (N 回)` | 生成が終わるのを待っている（ずっとこのままなら、終わったことを判定できていない） |
| `待機中 N 秒… (N 回)` | 次に押すまでの待ち時間 |
| `停止: 理由（N 回）` | 止まった。理由は下の表のどれか |

止まった理由:

| 理由 | 意味 | 通知 |
| --- | --- | --- |
| `最大回数に到達` | 最大回数だけ押した | 出す |
| `連続上限に到達` | 開始から連続上限の時間がたった | 出す |
| `Anlas を消費する設定になっています。ボタン表示「…」` | ボタンに Anlas の消費量が出ていた（「…」はそのときのボタンの文字） | 出す |
| `エラーが表示されました「…」` | NovelAI がエラーを表示した（「…」はエラーの文言） | 出す |
| `画面を移動` | 画像生成画面から別の画面に移った | 出す |
| `手動` | 「停止」を押した | 出さない |

パネル自体が出ないときは、拡張機能が有効になっているか、`https://novelai.net/image` を開いているかを確認してください。
